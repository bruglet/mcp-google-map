## Intentionally retained but unreachable source

The upstream weather, air-quality, timezone, static-map, and local-rank source files remain where removal would make future upstream synchronization needlessly noisy. They are not imported by `config.ts`, not present in the active tool allowlist, and not listed in the active CLI execution table. Their stale documentation is not copied into the runtime image.

This optimization pass intentionally does not remove or edit the retained local-rank implementation. Its unreachable status is the complete v1 control for that upstream feature.

## Upstream synchronization checklist

1. Fetch `upstream/main` and inspect upstream changes before merging.
2. Re-run `npm ci`, `npm run test:unit`, `npm run build`, `npm run lint`, and `npm run format:check`.
3. Re-check Places/Routes official SKU and field documentation.
4. Re-run the container, auth, ledger, Quadlet, and loopback boundary checks.
5. Update this file in the same commit for every new upstream-owned-file deviation.
